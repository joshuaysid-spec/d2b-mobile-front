# docs/spec — 사용자인터페이스설계서 (기획서)

팀 공통 참조용 **설계서 원본**을 이 폴더에 둔다. 로컬 절대경로(`C:\...`) 대신 이 상대경로(`docs/spec/`)로 참조해 **모두 동일 위치**를 쓴다.

> 사용자가 말하는 "기획서" = 이 **설계서**(사용자인터페이스설계서)와 같은 파일.

## 무엇을 두나

- 조달계획 설계서 pptx — 예: `D2BA-AP-3CD-0601.사용자인터페이스설계서-01조달계획-모바일_v0.6_상세.pptx`
- 도메인 추가 시(입찰/계약 등) 같은 규칙으로 이 폴더에 추가.

## 화면 목록 (화면ID ↔ 영문ID ↔ 한글명)

- pptx **slide5 "화면 목록"** 표가 매핑의 기준. 폴더명/파일명(설계서 영문 화면 ID)의 근거 = 이 표.
  (변환 규칙은 CLAUDE.md "설계서 화면 ID → 파일명 변환 규칙".)

## 페이지 ↔ 슬라이드 오프셋

- 슬라이드에 표시된 페이지번호 = `slideN - 1` (타이틀 슬라이드 1장 때문).
- 즉 "기획서 pXX"를 읽으려면 **`slide(XX+1).xml`** 을 본다. (예: p11~13 = slide12~14, MUI-OP-01-M02 검색필터.)

## pptx 읽는 법 (Read 도구로 직접 못 읽음 — 텍스트 추출)

- pptx를 zip 으로 풀어 `ppt/slides/slideN.xml` 의 `<a:t>` 텍스트를 추출.
- PowerShell: pptx를 `$env:TEMP` 에 `.zip` 으로 복사 → `Expand-Archive` → `[xml]` 로드 → `a:` 네임스페이스로 `//a:t` InnerText join.
